Case Study: EdTech & AI

GSTeacher AI: Coaching de Idiomas com IA

Setor

Educação / EdTech

Inovação

Análise de Pronúncia por IA

Stack Técnica

Django, OpenAI, Whisper, FFmpeg

O Desafio

Aprender um novo idioma exige feedback constante. Aulas particulares são caras e apps tradicionais são limitados. O desafio era criar uma plataforma que pudesse ouvir o aluno, analisar a gramática e a pronúncia, e fornecer feedback instantâneo e personalizado via Inteligência Artificial.

A Solução

O GSTeacher AI utiliza uma arquitetura de processamento assíncrono para lidar com arquivos de áudio pesados sem travar a interface do usuário.

  • Processamento de Áudio: Conversão e normalização de áudio via FFmpeg em background.
  • Integração de IA: Uso de modelos Whisper para transcrição e GPT-4 para análise linguística.
  • Feedback em Tempo Real: Notificações assíncronas para entregar o resultado assim que a IA termina a análise.
  • Gamificação: Sistema de pontuação baseado na precisão da pronúncia detectada.

Engenharia de IA

Integração de modelos de ponta com infraestrutura robusta:

// AI Pipeline
Audio Engine: FFmpeg + Python SoundFile
LLM: OpenAI API com engenharia de prompts customizada
Async Workflow: Celery Workers processando as tarefas de IA
Storage: AWS S3 para armazenamento seguro de gravações

O Resultado

"Uma plataforma capaz de avaliar milhares de horas de áudio por dia com precisão de um professor nativo."

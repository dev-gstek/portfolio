Case Study: Chrome Extension & CRM

WhatsApp CRM Pro: Funil Kanban & Prospecção B2B

Setor

CRM / Vendas / B2B

Minha Atuação

Desenvolvimento da Extensão & API de Integração

Stack Técnica

Manifest V3, Chrome Storage, Service Worker, REST APIs

O Desafio

Equipes de vendas B2B e SDRs passam horas buscando leads em sites e depois copiando e colando essas informações manualmente no WhatsApp Web para iniciar conversas. A falta de controle no fluxo de conversações e o esquecimento de follow-ups resultam em leads frios e perda significativa de oportunidades comerciais. O desafio era criar uma ferramenta leve que agilizasse a captação e organizasse os contatos diretamente na interface que o vendedor mais usa.

A Solução

Desenvolvi uma extensão nativa para Google Chrome (Manifest V3) que atua como um CRM integrado diretamente no WhatsApp Web, permitindo gerenciar leads e coletar novos contatos com apenas um clique.

  • Injeção de Interface (CRM): Um painel lateral de Kanban, botões de tags e campos de notas injetados na tela do WhatsApp Web sem quebrar o layout original do chat.
  • Scraper de Leads: Injeção de scripts inteligentes em diretórios e guias empresariais para coletar automaticamente nome da empresa, telefone e URL da página.
  • Processamento Assíncrono: Service Worker (`background.js`) que gerencia a comunicação e o roteamento de dados entre os content scripts de prospecção e o WhatsApp.
  • Sincronização Híbrida: Persistência local robusta via `chrome.storage.local` com sincronização automática para o banco PostgreSQL de um backend Django REST quando conectado.

Arquitetura & Mensageria

Funcionamento interno baseado nas diretrizes modernas do ecossistema de extensões do Google:

// Manifest V3 Extension
Content Scripts: `content/whatsapp/injector.js` monitora o DOM e injeta a UI de tags e funil.
Scraper Script: `content/prospector/scraper.js` identifica dados de contato no DOM de páginas web externas.
Background Worker: `background.js` centraliza o recebimento de mensagens e faz chamadas fetch autenticadas via JWT para a API.
Storage API: Cache local resiliente que impede perda de contatos caso o servidor de sincronização esteja indisponível.

O Resultado

"Agilidade e centralização do fluxo de trabalho de SDRs, reduzindo em até 70% o tempo gasto entre a busca do contato e o primeiro envio de mensagem no WhatsApp."
